## 判斷規則
- 獨立進修目的、資源足夠、已確認校系：優先評估研究所。
- 無獨立進修目的、資源足夠：優先準備律師。
- 資源不足：先安排收入與備考方式。
- 其餘：補資料後再決定。

規則尚未經成效驗證，不是錄取預測。成績只與使用者確認相同年度、組別、階段、計分方式的門檻比較，不用來推估機率或自動決定進修價值。
